# Making-of input evidence

These are preserved inputs from the original Memory Tape creation, not new AI generation performed during the CVA adoption.

- `scene-input.png`: one 1920×810 crop of the game video at 01:43:43. Black bars only were removed from the 1920×1080 frame. No inpainting or sharpening was applied to the SHARP input.
- `cassette-generated.png`: the separate 1880×837 generated isolation/completion image used in the initial TripoSR model lineage. It is not an original game frame and is not the source of the later separately supplied `aemeath_cassette.glb`.
- Source visual material: Wuthering Waves © KURO GAMES; unofficial fan study. Original project by mizan0515. Publication does not establish a general commercial asset license.
- Read [the case study](../docs/MEMORY_TAPE_CASE_STUDY.md) for model versions, recorded execution conditions, normalization and compression, later registration, camera choreography and verification limits.
